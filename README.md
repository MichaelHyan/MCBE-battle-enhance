## MCBE 原版战斗优化

### 使用方式

下载并安装BattleEnhance.mcaddon，适用与MCBE 1.21.110及以上

### 修改内容

#### 剑类

所有剑拥有格挡和横扫能力

横扫仿自java版横扫效果，伤害为面板的一半向上取整，有短暂cd

未装备盾牌时下蹲使用格挡，获得抗性3以及饥饿效果

#### 重剑类

加入新武器类型【重剑】

持重剑下蹲时可进行蓄力，共可蓄力三段，跳劈时将释放蓄力并造成范围伤害

蓄力一段跳劈造成50%面板额外伤害，二段100%，三段150%

合成方式为原版剑斜向摆放

面板，耐久，修复值和附魔与原版相同

#### 长矛类

持有时移动速度增快

#### 远程

优化准星为x型

大幅减少投射物弹道下坠

少许增加雪球伤害

骷髅掉落箭矢翻倍

持有弓时下蹲缩小视野,左键攻击回收箭

持有弩时下蹲大幅缩小视野并附加抗性提升

#### 三叉戟

浸入水中或雨中时获得暂时增伤效果

#### 重锤

平地起飞

从极高处掉落时不再受到掉落伤害

#### 指南针

手持指南针时额外显示方位

#### 鞘翅

装备鞘翅时自动补充烟花火箭

#### 羽毛

手持羽毛时不会误伤

攻击时产生风爆

#### 其他

奖励箱将可额外开出10-15火把

驯服的猫可能会带来更有价值的礼物

大幅降低苦力怕的生成概率，并提高火药爆率

加入自体技能【无伤】，在血条全满时稍有攻击力提升和冲刺速度提升

加入自体技能【火场怪力】，在血条较低时稍有攻击力提升和防御力提升，血条极低时攻击力和防御力大幅提升

加入自体技能【潜伏】，潜行一段时间后进入潜伏状态，可在此状态发动破隐攻击
